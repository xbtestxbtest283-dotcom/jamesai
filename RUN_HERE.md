# James AI — Local Run

1. Install Node.js 20+.
2. Open this folder in Terminal.
3. Run:
   npm install
   npm start
4. Open:
   http://localhost:3000

For AI:
- Put your OpenAI API key in `.env` as OPENAI_API_KEY=...
- Put your Google OAuth Web Client ID in `.env` as GOOGLE_CLIENT_ID=...
- In Google Cloud, add `http://localhost:3000` to Authorized JavaScript origins.

Do not share `.env` or your API key.
